# Flight Trip Optimizer v3.13

## 수정사항
- 새 브라우저 접속 시 이전 `generated` 상태를 자동으로 불러오지 않음
- 처음 접속하면 빈 여행 작업공간으로 시작
- `생성된 후보`는 사용자가 직접 `경로·발권 후보 생성`을 누르거나
  저장된 여행을 `불러오기` 했을 때만 표시
- 저장된 여행은 Cloud DB에 그대로 유지
- 새 여행 버튼도 빈 상태로 초기화

## 중요한 변화
이전 버전의 전역 `현재 작업` 자동복구는 제거했습니다.
대신 이름 붙여 저장한 여행은 사이드바에서 명시적으로 불러옵니다.

GitHub app.py 교체 → Commit/Push → Render 자동배포.
DATABASE_URL은 변경할 필요 없습니다.
