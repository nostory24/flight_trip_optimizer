# Flight Trip Optimizer v3.19.3

변경사항:
- `지금 검색/입력할 항공권 선택`에는 아직 저장된 유효 항공편이 없는 항목만 표시
- 항공편을 1개 이상 저장하여 체크리스트가 `✓ 입력 완료`가 되면 해당 항목은 선택 목록에서 즉시 사라짐
- 저장 후 붙여넣기 텍스트/추출 후보 초기화 기능 유지
- 완료된 항목은 전체 검색 체크리스트에는 계속 표시되어 진행상황 확인 가능
- 모든 항목이 완료되면 선택창 대신 완료 메시지 표시
