# Flight Trip Optimizer v3.21

## 자동 연결 안전성 수정

v3.20 문제:
- 경유지/페이지 내 다른 공항명이 매칭 점수에 영향을 줄 수 있었음
- 날짜만 비슷한 다른 구간으로 잘못 연결될 위험이 있었음

v3.21:
- 붙여넣은 텍스트의 '명시된 출발지 → 최종 도착지'만 사용
- 경유지 공항은 체크리스트 판별에 사용하지 않음
- 편도는 방향까지 정확히 일치해야 함
- 왕복은 두 끝점 + 왕복 표시가 일치해야 함
- 날짜가 텍스트에 있으면 체크리스트 날짜도 일치해야 함
- 후보가 없거나 2개 이상이면 저장 금지
- 저장 버튼 클릭 시 동일 로직으로 다시 검증
- 수동 항공권 선택 드롭다운 없음

예:
ATH → JTR 결과는 ATH → JTR에만 저장 가능.
ATH → ICN에는 절대 자동 저장하지 않음.

중요:
붙여넣을 때 검색 페이지 상단의 구간명도 함께 복사해야 합니다.
구간명이 없으면 안전을 위해 저장하지 않습니다.
