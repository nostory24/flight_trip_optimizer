# Flight Trip Optimizer v3.20.0

수정:
- 일정에 없는 synthetic side-trip 자동 생성 제거
- 실제 itinerary_stays에 입력된 이동만 체크리스트에 사용
- 왕복 후보는 실제 일정에 양방향 이동이 존재할 때만 생성

예시 일정:
ICN 출발 12/23
IST 12/24 도착 / 12/27 출발
JTR 12/27 도착 / 12/29 출발
ATH 12/29 도착 / 1/2 출발
ICN 1/3 도착

실제 이동:
ICN -> IST -> JTR -> ATH -> ICN

따라서:
- JTR -> ATH / 12/29: 생성
- ATH -> JTR / 1/2: 생성하지 않음

반대로 사용자가 실제로 ATH -> JTR -> ATH 일정을 날짜 추가로 입력한 경우에만
ATH <-> JTR 왕복 발권 후보를 생성합니다.

기존 저장/불러오기, 자동저장, 완료항목 숨김, 원래 체크리스트 번호 유지 기능은 유지합니다.
