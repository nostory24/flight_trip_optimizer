# Flight Trip Optimizer v3.20.1

수정:
- 모든 항공권 입력 완료 시 `st.stop()`으로 앱 전체 실행이 중단되던 문제 수정
- 완료 후 2번 탭의 입력 UI만 종료
- 3번 `조합/랭킹` 탭은 계속 렌더링 및 계산
- 완료 메시지에서 조합/랭킹 탭으로 이동 안내

원인:
`st.stop()`은 현재 탭만 멈추는 것이 아니라 Streamlit script 전체를 중단하므로,
뒤쪽의 조합/랭킹 코드가 실행되지 않았습니다.

기존 저장/불러오기, 완료항목 숨김, 체크리스트 번호 유지,
일정에 없는 역방향 후보 제거 기능은 유지합니다.
