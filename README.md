# Flight Trip Optimizer v4.1

## 조합 선택을 `전체 검색 체크리스트` 기준으로 변경

3. 조합/랭킹의 체크 표에서 R1-P1 같은 내부 패턴 이름을 사용자에게 보여주지 않습니다.

예:
- [편도] ICN → IST
  + [편도] IST → JTR
  + [편도] JTR → ATH
  + [편도] ATH → ICN

- [다구간] ICN → IST → JTR → ATH → ICN

- [왕복] ... + [편도] ...

각 행 전체가 하나의 가격 비교 조합이며 `조합 포함` 체크로 즉시 ON/OFF합니다.

풀구간 다구간도 체크리스트의 다구간 티켓 1개 조합으로 동일하게 체크/해제할 수 있습니다.

내부 R1-P* ID는 계산용으로만 유지하고 UI에서는 숨깁니다.
