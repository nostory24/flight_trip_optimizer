# Flight Trip Optimizer v4.2

## 체크리스트 기준 항공권 삭제

`2. 검색결과 입력 > 저장된 항공편`의 삭제 기능을 변경했습니다.

- `전체 검색 체크리스트`에 현재 존재하는 항공권만 삭제 목록에 표시
- 각 체크리스트 항목별 저장 후보 개수 표시
- 선택한 체크리스트 항목의 저장 후보만 일괄 삭제
- 다른 search_key / 예전 일정 잔여 데이터는 삭제 목록에 표시하지 않음
- 기존 `저장 항공편 전체 삭제` 버튼 제거

예:
3. [편도] IST → JTR — 저장 후보 11개

선택 후 삭제하면 IST→JTR에 해당하는 저장 후보 11개만 삭제됩니다.
다른 ICN→IST, JTR→ATH, 다구간 데이터는 유지됩니다.
