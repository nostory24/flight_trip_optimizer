# Flight Trip Optimizer v3.20.7

## 발권 조합 단위 포함/제외

`조합 포함`은 개별 항공권이 아니라 R1-P1, R1-P2 같은 발권 조합 전체에 적용됩니다.

- 1. 여행/경로 > 생성된 후보 표에서 `조합 포함` 체크
- 체크된 발권 패턴만 2. 검색 체크리스트에 반영
- 체크된 발권 패턴만 3. 조합/랭킹 계산에 반영
- 체크 해제한 패턴 때문에만 필요한 항공권 검색도 체크리스트에서 제외
- 선택 상태는 여행 저장/불러오기 및 자동저장 시 유지

개별 티켓의 `조합 포함/계산 포함` 체크는 제거했습니다.

## 다구간

Skyscanner에서 다음처럼 여러 구간이 한 결과 세트로 복사되는 형식을 지원합니다.

ICN -> IST
IST -> JTR
JTR -> ATH
ATH -> ICN
(마지막에 전체 가격 1회)

- 각 requested leg의 항공사/출발/도착/경유/소요시간을 별도 segment로 저장
- 전체 다구간 가격은 티켓 한 세트 가격으로 1회만 계산
- 랭킹 상세에서 segment를 각각 표시
