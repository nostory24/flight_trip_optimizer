# Flight Trip Optimizer v3.20.4

## 티켓별 `계산 포함` 옵션

저장된 각 항공권에 `계산 포함` 체크박스를 추가했습니다.

- 체크: 조합/랭킹 계산에 사용
- 체크 해제: 데이터는 저장된 상태로 유지하지만 조합/랭킹에서는 제외
- 신규 티켓은 기본적으로 체크됨
- v3.20.3 이전에 저장된 기존 티켓도 기본적으로 체크된 것으로 처리

`2. 검색결과 입력 > 저장된 항공편 · 계산 포함 선택`에서 변경할 수 있으며,
`3. 조합/랭킹 > 수하물 옵션 반영`에서도 같은 값을 수정할 수 있습니다.

체크 해제한 티켓은 삭제되지 않으므로 다시 체크하면 즉시 비교 대상에 복귀합니다.

GitHub app.py 교체 → Commit/Push → Render 자동배포.
